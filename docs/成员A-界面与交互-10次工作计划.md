**角色**：UI 与交互（同时负责共享文件与最终整合）
**分支**：`feat/a-ui`

## 工作目录（只能在这里面新建/修改/删除/移动文件）


**红线**：不得修改 `data/**`（B 的）和 `player/**`（C 的）里的任何文件。只能 `import` 它们的接口，不能改。
**共享文件**：以上标了"共享"的文件由你统一维护；B/C 会提需求给你。
**提交规范**：每次提交 = 本次代码 + `ui/README.md` 工作记录章节更新，且要有一定行数代码；分 10 天提交 10 次。

## 第 1 次｜工程地基：规范、主题、依赖、骨架

- **目标**：把整个工程跑起来，三人后面的工作都站在这个地基上。
- **主要任务**：
  1. 建 Android 工程（Kotlin），包名 `com.team.vplayer`，minSdk 24 / targetSdk 34。
  2. 建好目录结构（见 README 第 4 节），把三个模块的空包建出来。
  3. 写 `libs.versions.toml`，统一加入三人需要的依赖：
     - Media3：`media3-exoplayer`、`media3-ui`、`media3-session`（给 C）
     - Room + KSP（给 B）、Coil、Material Components、Coroutines、ViewModel（给大家）
  4. 在 `AndroidManifest.xml` 加好权限：`READ_MEDIA_VIDEO`、`READ_EXTERNAL_STORAGE(maxSdk=32)`、`POST_NOTIFICATIONS`、`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PLAYBACK`、`WAKE_LOCK`、`SYSTEM_ALERT_WINDOW`。
  5. 定主题：配色、字号度量、`values-night`；写 `ui_strings.xml`。
  6. 做 App 图标、启动页；`App.kt`、`MainActivity` + 底部导航三个 Tab（首页/历史/设置）骨架。
  7. 写 `common/ServiceLocator.kt`（暴露 `videoRepository` 与 `playback`）。
  8. 创建 `ui/README.md`，写好模块说明 + 工作记录章节。
- **涉及文件**：`build.gradle.kts`、`settings.gradle.kts`、`gradle/libs.versions.toml`、`AndroidManifest.xml`、`res/values/*`、`res/values-night/*`、`res/drawable/*`、`res/mipmap*/*`、`App.kt`、`common/ServiceLocator.kt`、`ui/MainActivity.kt`、`ui/home/HomeFragment.kt`（空壳）、`ui/README.md`。
- **完成标准**：真机能安装启动，底部三个 Tab 可切换空白页；编译无错。
- **完成后**：更新 `ui/README.md` 工作记录章节（第 1 次），连同代码提交到 `feat/a-ui`。

## 第 2 次｜首页视频列表 UI

- **目标**：把"视频列表"页做出来（先用假数据，第 4 次换真数据）。
- **主要任务**：
  1. `RecyclerView` 网格/列表两种视图，卡片含缩略图、标题、时长、大小、所在文件夹。
  2. 空状态（没视频时显示引导去扫描）、下拉刷新、加载中状态。
  3. 顶部排序菜单（名称/时长/大小/时间）与视图切换（网格/列表）。
  4. 顶部搜索框与文件夹筛选条（先做 UI，逻辑留接口）。
- **涉及文件**：`ui/home/**`、`res/layout/fragment_home.xml`、`res/layout/item_video.xml`、`res/values/ui_strings.xml`。
- **完成标准**：假数据下列表美观、排序/切换有反馈。
- **完成后**：更新 `ui/README.md` 工作记录（第 2 次）并提交。

## 第 3 次｜播放页布局

- **目标**：播放页的"形"出来。
- **主要任务**：
  1. `PlayerActivity` + `PlayerView`（Media3 的 `PlayerView` 或 `StyledPlayerView`）容器。
  2. 顶部栏（返回、标题、更多菜单）、底部控制条（播放/暂停、当前/总时长、`SeekBar`、上/下一首）。
  3. 锁定按钮、全屏/横竖屏切换、控制条自动隐藏。
  4. 菜单入口占位：倍速、字幕、音轨、定时关闭、PIP、悬浮窗。
- **涉及文件**：`ui/player/**`、`res/layout/activity_player.xml`、`res/layout/view_player_control.xml`。
- **完成标准**：能打开播放页看到布局，控件可点（逻辑先留空）。
- **完成后**：更新 `ui/README.md` 工作记录（第 3 次）并提交。

## 第 4 次｜播放页交互逻辑

- **目标**：让播放页真正能控制播放，并接真数据。
- **主要任务**：
  1. 绑定 C 的 `PlaybackController`（`ServiceLocator.playback`）和 B 的 `VideoRepository`（真数据替换假数据）。
  2. 播放/暂停、进度条拖动、上/下一首、倍速/字幕菜单。
  3. 单击显示/隐藏控制条、双击播放/暂停、进度条拖动预览。
  4. 倍速/字幕/定时菜单弹窗（`PopupWindow`/`BottomSheet`）。
  5. 加载中、播放完成、播放错误三种状态的界面反馈。
  6. **生命周期约定**：`onDestroy` 只解绑（`playerView.player = null`），不调 `release`。
- **涉及文件**：`ui/player/**`、`ui/home/**`。
- **完成标准**：真数据点开视频能播，所有控件反应正确。
- **完成后**：更新 `ui/README.md` 工作记录（第 4 次）并提交。
